# Collector's Edition — Legal

Privacy Policy hosting for [Collector's Edition](https://collectorsedition.app) iOS app.

Hosted on GitHub Pages with custom domain via Cloudflare.

- English: https://collectorsedition.app/privacy/
- Türkçe: https://collectorsedition.app/privacy-tr/
- Terms of use: [Apple Standard EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)

## Stack

- GitHub Pages (Jekyll, minima theme)
- Cloudflare DNS (custom domain `collectorsedition.app`)
- Markdown with frontmatter

## Update Process

1. Edit `privacy.md` or `privacy-tr.md`
2. Update the `Effective Date` field
3. Commit and push — GitHub Pages rebuilds automatically (1-2 min)
